# Task 1 Keyword recognition

The board records a two-second clip and computes a 124 × 32 log-mel feature matrix. Your computer saves the examples and trains a six-class CNN. You then copy the exported model back to the board to recognize new recordings.

Work from the `task1` folder when running the commands below. Use your Python environment with the packages in `requirements_train.txt`. On macOS use `python3`; on Windows use `py` or the Python command for your active environment.

## Collect examples

Open `keyword_collect/keyword_collect.ino`. Select XIAO_ESP32S3, USB CDC On Boot enabled, and OPI PSRAM. Install arduinoFFT 2.0.4. Complete TODO 1.1 in the sketch and TODO 1.2 in `tools/collect_keywords.py`, then upload the sketch. Close Serial Monitor before using the collector.

First find the board's current port:

```text
python3 tools/collect_keywords.py --list-ports
```

Replace `YOUR_PORT` with the port you found. This example collects 30 training recordings of the word `wake`:

```text
python3 tools/collect_keywords.py --port YOUR_PORT --output dataset --label wake --session train_01 --split train --count 30
```

Press Enter to request each recording. Speak after `RECORDING`, while the LED is on. Wait for `[SAVED]` before the next example. Collect your five keywords and the label `unknown`. Include unrelated words, silence, and background sounds in `unknown`.

Use separate recording sessions for the three splits. For each class, collect at least 30 train, 10 val, and 10 test examples. Change the session name and split together for each separate session, such as `val_01 --split val` and `test_01 --split test`. Reposition yourself and the board between sessions. Keep all examples from one session in one split.

Each sample has matching `.wav` and `.npy` filenames, with its label, session, and split in `dataset/labels.csv`. Inspect the counts and first sample:

```text
python3 tools/inspect_dataset.py --dataset dataset
```

To inspect another sample, add `--sample` followed by its ID from `labels.csv`. The command checks all feature matrix shapes, prints the selected WAV's sample count and duration, and saves its feature plot in `dataset/inspection`. Listen to the WAV and check its label before training.

## Train the model

Complete TODOs 1.3–1.5 in `tools/train_keywords.py`. The provided `training_support.py` loads the files, checks the session split, exports the model, and draws the evaluation plots.

```text
python3 tools/train_keywords.py --dataset dataset --output trained_model --epochs 50 --batch-size 4
```

Training writes `training_curves.png`, `confusion_matrix.png`, and `metadata.json`, along with the model files. The acceptance threshold is selected using validation data. The held-out test set is used for the final evaluation. Choose a new output folder for another training run, such as `trained_model_2`.

## Run the model on the board

Copy BOTH `model_data.h` and `model_config.h` from the same training output folder into `keyword_inference`. These files are generated by training and are not included in the starter. `model_config.h` contains the learned normalization values, quantization parameters, class labels, and acceptance threshold. Keep the hand-written `config.h` already in the sketch folder.

Install Chirale_TensorFLowLite 2.0.0. Complete TODOs 1.6–1.7 in `keyword_inference/keyword_inference.ino`, then upload it with the same board settings. Open Serial Monitor at 115200 baud.

Send `r` to record one two-second clip. Send `a` for repeated recordings or `s` to stop repeating. Speak only after the recording cue. The board prints the candidate, accepted prediction, all class scores, and timing. `UNKNOWN` means either the unknown class won or the largest score was below the exported acceptance threshold.

`frontend_ms` measures feature extraction; `inference_ms` measures the CNN call. Their running averages are `mean_frontend_ms` and `mean_inference_ms`. `capture_ms` is the recording time; `cycle_ms` also includes microphone startup and processing. The two-second recording is not included in CNN inference time.
